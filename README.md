FX Converter ToolA simple HTTP service built with Python and FastAPI to convert currencies using the European Central Bank (ECB) rates via frankfurter.dev. It acts as a reliable tool for an AI agent runtime, ensuring precise currency conversions and transparent date handling.How to Run./run.shThe service will start on port 8080 by default. You can override this by setting the PORT environment variable (e.g., PORT=9000 ./run.sh).How to Run the Tests./test.shThe test suite uses pytest and respx. It is designed to run entirely offline by pointing the upstream URL to a closed port and mocking the external API responses.Error CodesWhen an error occurs, the API returns a non-2xx status code with a JSON payload containing an error machine code and a human-readable message.HTTP StatusError CodeDescription400invalid_inputMissing required parameters (e.g., amount is missing).400invalid_amountAmount is zero, negative, or has too many decimal places (max 9).400same_currencySource (from) and target (to) currencies are identical.400invalid_date_formatThe provided date is not in YYYY-MM-DD format.400future_dateThe requested date is in the future.400date_too_oldThe requested date is before 1999-01-04 (before the series starts).400currency_not_foundThe currency code does not exist.502upstream_timeoutThe upstream API took too long to respond (timeout set to 5s).502upstream_errorThe upstream API returned an unexpected HTTP error (e.g., 500).502upstream_unavailableThe upstream API is unreachable or returned invalid JSON.Edge Case HandlingThe endpoint is designed to never invent a rate and always be transparent about the data it provides:No rate for the date asked (weekends, holidays, or not published yet): If the ECB hasn't published rates for the requested date (e.g., it's Sunday, or today's rate isn't out yet), the upstream returns a 404. The service intercepts this and fetches the /latest valid rates instead. To maintain transparency, the response explicitly sets asked_date to the user's requested date, and rate_date to the actual date the ECB published the rate.The date is in the future, or before the series starts: The request is rejected instantly at the FastAPI validation layer with a 400 error (future_date or date_too_old). The upstream API is never called.The currency code does not exist, or from and to are the same: If the currencies are the same, it fails instantly with same_currency. If the currency code doesn't exist, the upstream returns a 404, which is caught and safely returned to the user as a 400 currency_not_found error.The upstream is slow, returns 500, or returns non-JSON: Wrapped in a try/except block. Slow responses trigger an httpx.TimeoutException. Non-JSON responses trigger a ValueError. 500 errors are caught via raise_for_status(). All are gracefully returned as 502 Bad Gateway errors.Amount is missing, zero, negative, or has 10 decimal places: Validated upon request entry. If missing, it raises an invalid_input error. If <= 0 or if the decimal length exceeds 9 places, it raises an invalid_amount error.
